@快速开始@
LIDE 是 Android 上的 Lua 集成开发环境，兼容 AndroLua Pro 工程。
首次启动后，首页会列出示例工程。
点击工程进入编辑器，点播放键即可运行。
脚本运行在独立的引擎页面中；按返回键回到编辑器。

@工程与文件@
工程是包含 init.lua 与 main.lua 的目录。
init.lua 声明工程元数据：appname、appver、packagename、user_permission 等。
这些字段可在「工程属性」中修改（工程列表长按工程）。
编辑器内的文件树展示工程全部文件，点击以标签页打开。
工程 libs/ 目录中的库（.dex / .so / .lua）会被自动加载。

@编辑器@
编辑器支持语法高亮、括号匹配与行级诊断。
自动换行与空白字符显示可在设置中开关。
字体大小与制表符宽度在设置中调整，实时生效。
Ctrl+F（触屏键盘上为长按工具栏）打开文件内搜索。
未保存的修改会自动落盘；关闭脏标签时会有确认提示。

@运行与诊断@
运行始终跟随当前标签：main.lua 运行整个工程，其他文件只运行该文件。
运行前，init.lua 声明的权限会通过系统对话框一次性请求。
脚本出错时，编辑器会展示错误文本，并可一键跳到出错行。
「nil value (global 'X')」类错误提供「插入 import」快捷操作。

@权限@
宿主权限在「设置 > 权限」中查看与管理。
工程权限（init.lua 的 user_permission）显示在工程权限页。
特殊权限（悬浮窗、修改系统设置、电池优化等）跳转系统设置页。
打包时工程声明的权限会写入产物 APK 的 manifest。

@API 浏览器@
「设置 > API 浏览器」列出脚本可见的全部 Java 类。
按名称搜索、按分类过滤；点开类查看构造器与方法。
长按类名可复制到剪贴板。
运行时不可加载的类以中划线显示。

@示例@
「设置 > 示例」提供示例工程（.alp 包）。
导入示例会复制到你的工程列表，可像普通工程一样编辑。

@打包 APK@
「打包 APK」将当前工程打包为可安装的 APK。
打包流程：Lua 源码编译 → manifest 补丁 → 重打包 → v1+v2 签名。
产物保存在应用缓存目录，可分享或安装。
打包为实验性功能；请在其他设备上验证产物 APK。

@设置@
外观：主题模式（跟随系统 / 浅色 / 深色）与强调色。
编辑器：自动换行、空白字符、字体大小、制表符宽度。
语言：中文或 English（切换后界面重建）。
帮助：本文档。

@常见问题@
示例不显示：为应用开启「所有文件访问」权限后重新进入首页。
提示「Writable dex file」：Android 8+ 不允许从可写目录加载 dex，请将 .dex 库放入受保护目录。
脚本无声音：检查设备是否静音，音频遵循系统设置。
崩溃反馈：保留应用日志并描述复现步骤。
